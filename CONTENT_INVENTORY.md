# Content and dependency inventory

All demonstrations are educational and AI-assisted. The dataset in `demo-run.json` is reproducibly generated from a seed. `mission-data.js` and `scenario-app.js` contain invented examples, not personal records. The structure reference is a newly drawn generic SVG schematic, without an identifiable person or private location. Actual interface screenshots, when present, depict this demonstration only.

Bundled dependencies:

- Leaflet 1.9.4 — BSD-2-Clause; https://github.com/Leaflet/Leaflet
- topojson-client 3.1.0 — ISC; https://github.com/topojson/topojson-client
- world-atlas 2.0.2 — ISC package; Natural Earth geographic data in the public domain; https://github.com/topojson/world-atlas

Attribution is retained in the map and `THIRD_PARTY_NOTICES.txt`. There are no advertising, analytics, login or contact widgets. No real backend endpoint or provider key is included.
