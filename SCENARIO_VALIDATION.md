## Browser integration

The public interface is checked for local map loading, category filtering, selected-event evidence, hypothesis changes and the contribution audit. For the fixtures in the base state, basket scores are 3.60, 1.30 and 0.70 arbitrary units. The disruption multiplier produces 5.76, 2.08 and 1.12. Audit components must sum to those same values.

These are deterministic model checks on invented examples. They are not measurements of predictive accuracy, event-detection quality or operational situational awareness.

## Scope

No live feed, private event archive, personal location, account data, provider credential or original private decision engine is present. No empirical calibration or production assessment was conducted. Static map geometry is bundled and has no relation to private operating sites.
