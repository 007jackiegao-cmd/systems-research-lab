# Project Catalogue

## SMART3D · Parametric Design & Assembly

**Design the logic. Build the geometry.** An interactive design workbench connecting dimensions, real mesh Boolean computation, reusable assembly instances, structured BOM data and GLB export. The public source includes focused constructors; the wider original backend remains private.

[Live workbench](https://007jackiegao-cmd.github.io/smart3d-showcase/) · [Repository and architecture](https://github.com/007jackiegao-cmd/smart3d-showcase)

## Quant Signal Lab · Quantitative Research

**Research the signal. Inspect the risk.** A reproducible research workflow connecting seeded prices, lagged exposure, explicit turnover costs and equity/drawdown/volatility diagnostics. The browser implementation is checked against a Python reference.

[Live workbench](https://007jackiegao-cmd.github.io/quant-signal-lab/) · [Repository](https://github.com/007jackiegao-cmd/quant-signal-lab) · [Methodology](QUANT_METHODOLOGY.md)

## Scenario Intelligence Lab · Situational Awareness

**See the context. Trace the scenario.** A geospatial event-and-scenario interface exposing manual weights, hypothesis multipliers, signed contributions and opposing effects. All events and scores are illustrative.

[Live workbench](https://007jackiegao-cmd.github.io/scenario-intelligence-lab/) · [Repository](https://github.com/007jackiegao-cmd/scenario-intelligence-lab) · [Methodology](SCENARIO_METHODOLOGY.md)

## Mission Review Lab · Evidence-driven Workflows

**Operational progression with inspectable evidence.** A task/resource/review interface with fictional roles, explicit versions and generic schematic evidence. Changes remain temporary in the current page.

[Interface](mission.html) · [Case study](MISSION_PROJECT.md)

## Engineering Computation Lab · Numerical & Asynchronous Systems

**Compute. Check. Explain.** Python examples exposing pressure-balance and thermal calculations alongside explicit fallback, freshness, cancellation and capacity policies for a synthetic data cache.

[Case study and run commands](ENGINEERING_PROJECT.md)

## Shared status

All entries are public demonstrators with a stated validation scope. No full production deployment, empirical trading edge, calibrated operational intelligence or original research-code publication is implied. Source guides, methodology and evidence are the primary review paths.
