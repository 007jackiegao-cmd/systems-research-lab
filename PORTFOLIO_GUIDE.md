# Reviewer Guide

## Start with the system that matches your interest

| Interest | Suggested review path |
|---|---|
| Computational design / CAD | SMART3D: change a dimension, inspect the assembly, export a model and read the validation note |
| Quantitative research | Quant Signal Lab: change lookback/cost, inspect risk views and examine time alignment and parity checks |
| Situational awareness / explainability | Scenario Intelligence Lab: filter events, switch hypotheses and compare contribution components with aggregate scores |
| Engineering workflows | Mission Review Lab: inspect the sample task, evidence versions and reviewer context |
| Numerical / asynchronous software | Engineering Computation Lab: inspect solver outputs and the cache's failure/cancellation policies |

## Three layers of review

1. **Behaviour:** open the demonstration and change an input.
2. **Implementation:** follow the unminified source and methodology.
3. **Evidence:** inspect the named checks and what they establish.

Synthetic fixtures allow the examples to run without private accounts, live providers or original project data. Validation labels deliberately separate a computation check, a browser interaction, an exported file and a full system deployment.

## Public/private boundary

The portfolio exposes focused public examples and technical explanations. Personal records, environment configuration, database backups, original source archives, core development modules and private operating assets are outside the public package. Earlier repositories containing superseded material remain private.
